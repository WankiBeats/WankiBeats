WANKI BEATS WEBSITE - HOW TO USE

1) Pick your 3 best beats.
2) For each one, cut the BEST 30-45 seconds (the hook or the drop) and export as MP3 (128-192 kbps).
   Do not upload the full beat. A short preview loads fast and protects your beat.
   Tip: add your voice tag in the preview.
3) Name them beat-1.mp3, beat-2.mp3, beat-3.mp3 and put them in the "audio" folder.
4) Open index.html in a text editor and find "EDIT YOUR 3 BEATS HERE" near the bottom.
   Change the name and the tag (genre + BPM) for each beat.
   If you uploaded a full beat instead, set start (second where the preview begins) and len (seconds, e.g. 30).
   The site will only play that part.
5) Upload the whole folder to GitHub (index.html + audio folder), then turn on
   Settings > Pages > Deploy from a branch > main > / (root).

Note: the beat-reactive visualizer needs the site to be hosted (GitHub Pages). If you just double-click
index.html on your computer, the visualizer still moves but it will not react to the real audio.
